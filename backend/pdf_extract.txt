Problem Statement:
Current AI assistants are largely stateless and
rely primarily on chat logs or embedding-
based retrieval. They:
Fail to maintain structured long-term
memory per user
Cannot explain why a specific answer
was generated
Struggle to scale memory without chaos
Retrieve information inefficiently as data
grows
Lack strict user-level memory isolation
Proposed Solution:
We propose GraphMind, a user-centric AI
assistant that:
Builds a structured, evolving graph
memory per user
Stores facts, entities, events, preferences,
and relationships
Uses hybrid retrieval (Graph traversal +
optional vector search)
Generates explainable, evidence-backed
responses
Displays real-time retrieval performance
GraphMind transforms conversations into
structured intelligence instead of temporary
chat history.

--- PAGE 3 ---
Approach/Method
A) User-Scoped Two-Layer Memory Model:
Each user has an independent cognitive memory
space:
Ephemeral Layer (Short-Term)
 • Stores raw interaction signals
 • Unverified entities, topics, preferences
 • TTL-based & reinforcement-driven
 • Filtered via transformer-based semantic
scoring
Consolidated Graph Memory (Long-Term –
Neo4j)
 • Stores validated knowledge only
 • Nodes: User, Entity, Fact, Preference, Event,
Goal, DocumentChunk
 • Edges: MENTIONS, RELATED_TO, PREFERS,
WORKS_ON, HAPPENED_AT, DERIVED_FROM,
CONFIRMS, CONTRADICTS
Retrieval Rules:
 • Anchored at User
 • ≤ 3-hop traversal
 • Strict user isolation
B) Controlled Memory Ingestion & Promotion
Pipeline:
Extract → Score → Assign Metadata → Temporary
Store → Conditional Promotion
Promotion occurs only if:
 • Reinforced multiple times
 • High semantic importance
 • Linked to concrete action
Graph updates use MERGE normalization with
incremental updates to confidence & last_reinforced.
Prevents graph explosion while enabling structured
evolution.
C) Graph-First Hybrid Retrieval Strategy:
Deterministic retrieval pipeline:
1.User-anchored graph traversal (primary retrieval)
2.Optional vector similarity search (Milvus) for long-
form content
3.Context assembly: ranked nodes + evidence +
source references
Graph = Source of Truth
 Vector DB = Semantic Enrichment

--- PAGE 4 ---
1. Confidence & Reinforcement-Based Memory
Each memory node tracks confidence,
reinforcement count, and recency, allowing
knowledge to strengthen through repeated use and
decay when unused.
2. Contradiction-Aware Knowledge Storage
Conflicting facts are preserved and explicitly linked
rather than overwritten, enabling transparent
reasoning and historical traceability.
3.Deterministic & Explainable Retrieval
Every response is grounded in retrieved memory
nodes, with clear evidence paths and relevance
scores, eliminating black-box behavior.
4. Precomputed Intelligence Cache
Frequently used insights such as high-confidence
concepts, trends, and summaries are computed
asynchronously and cached for fast retrieval.
5. Bounded & Predictable Query Performance
User-anchored traversal with strict depth limits
ensures consistent performance as memory grows.
6. Hybrid Structured + Semantic Memory
Structured knowledge is stored in the graph, while
semantic embeddings are used only for long-form
text retrieval, preventing semantic noise.
7. Memory Audit & User-Governed Control
Users can inspect stored memories, view their
provenance and reinforcement history, and
selectively correct or delete entries to maintain
accuracy and trust.

--- PAGE 7 ---
Enhancements(Beyond Basic)
1.Real-Time Coding Behavior Tracking
A VS Code extension continuously captures coding
behavior such as time spent, errors, edits, and stuck
time, enabling fine-grained understanding of
problem-solving patterns.
2. Adaptive Question & Difficulty Engine
Practice questions and hints dynamically adapt
based on mastery score, improvement velocity, and
recent performance instead of fixed difficulty levels.
3. Communication Skill Intelligence
Speech recordings are analyzed for confidence,
filler words, grammar, and pacing, with improvement
trends tracked across sessions and linked to
interview readiness.
4.Company-Aware Readiness Analysis
Company hiring focus is mapped directly to user
weaknesses to compute a Company Readiness
Score, highlighting high-risk topics for targeted
preparation.
5.Current Affairs & Context Awareness
News articles are ingested, classified by
policy/domain relevance, and linked to preparation
topics, supporting HR and civil-services-style
interviews.
6.Insight Feed with Actionable Signals
The system surfaces high-impact insights such as
repeated weaknesses, improvement milestones,
and preparation priorities instead of raw data.
